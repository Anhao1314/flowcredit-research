# FlowCredit 开发进展 · 2026-09-13

取代 9 月 5 日快照中的当前状态。范围为 `flowcredit-v2` 开发与测试仓库，没有部署、发布、生产移植或平台提交。

## 已完成

浏览器离线确定性评估、示例优先入口、报告打印/PDF 与 JSON 快照、草稿持久保存已由既有提交完成。本轮完成单一结果与布局、九字段渐进表单、示例填充、错误标签、proof 与场景降级、首页能力措辞、独立模型授权和开发者说明。

九个起步字段为名称、起止日期、输入/输出 Token、GPU 类别/小时、收入、算力支出。补充项默认收起，错误所在组自动展开。缺少维度保持 Not computable，不用演示数值填充。修改事实会清除旧结果、proof、在线会话和解释授权。

示例、离线与在线共用草稿结果页面；旧评分、Saved AI 第二套裁决和旧案例分叉退出用户界面。报告中的 mock-hash 一致性检查可选，不验证真实性、不产生链上交易、不影响完成进度；场景附录是固定值示意，不预测用户业务或持续监控。

## 冻结与契约核对

`data.js`、`state.js`、`ui.js`、生成引擎及 `agent/src/` 本轮零改动。app.js 和首页仅按有限解冻改展示，路由、原事件绑定、状态机、公式、mock 数值与计时零改动。旧压力时序保留于内部状态机。

API、intake、风险结果和快照版本未变；既有输入/输出 schema、字段与确定性公式未变。浏览器分别记录抽取/解释授权，仍按调用目的发送既有 `modelConsent` 字段。
