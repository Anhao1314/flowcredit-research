3规则引擎 App.fn · L0→L5 流水线（纯函数现算，禁止写死结果）

L0 采集 → L1 折算 → L2 过滤 → L3 五锚核验 → L4 评分 → L5 链上存证
L1 口径
  • Raw Token 唯一口径：d.l0.compute.Raw（healthy 80.0M / sybil 108.0M）
  • rawNT_M = 已乘 w_model×w_task（96.0M / 108.0M），仅用于 L2 毛 NT
  • SCU = GPU·h × util × c_gpu（3,570 / 86.1）
L2 去水分
  • ValidRate：healthy 94% / sybil 34%
  • ValidNT：90.2M / 36.7M（"毛值更高、有效反低"的核心反转）
L3 五锚（权重 .25/.25/.20/.15/.15）
  • Efficiency 22,857·76｜Repayment 96%·88｜Customer 36%·86｜Cost·70｜Time/Sybil·72
  • 同业带 [lo,hi] 打分红/黄/绿；硬规则命中 → 一票否决 VETO
  • sybil：效率/回款/客户/女巫 4 项红旗 → D、额度 0
L4 评分与量化
  • CCI = Σ(score×weight)×10 → 795 / 320
  • PD = 1/(1+e^(0.01156·CCI−5.433)) → 2.3% / 85.0%
  • 等级五档：A≥800 / A- 750–799 / B 650–749 / C 500–649 / D<500（VETO 强制 D）
  • 双价值背离 D=(R−C)/C：+3% 正常 / +186% 越 2σ 告警
L5 / 决策输出
  • Merkle mock：叶子(data|ts|nonce) → root；anchor 保存最新 root 与层级
  • 额度：VETO→$0，否则 $20,000（演示校准）
  • 贷后响应帧：额度 20,000→12,000→18,000；HF 1.85→1.05→1.35，清算线 1.00
