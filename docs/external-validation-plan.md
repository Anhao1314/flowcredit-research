## Five-minute usability session

A participant outside the project understands that the example is synthetic and the rules experimental. Observe without completing the task for them.

1. Open index.html offline and find the worked example.
2. Explain the status, one evidence limitation and one next action.
3. Enter authorized real facts or basic facts and obtain a limited result.
4. Find a missing input, add it, rerun and explain the change.
5. Print/export the report and restore JSON in a separate browser context.

Record participant code, synthetic/real-data status, time to first result, completion, navigation failures, explanation accuracy, export use and return to supplement evidence. Do not record raw evidence or identifying details by default.

Acceptance: the participant independently obtains, explains and preserves a result, then finds the next evidence action. The 30-second example and five-minute task targets remain hypotheses until measured. Roadmap targets remain one external assessment, ten qualified assessments and one repeat caller; developer fixture runs do not count.
