# Evidence Analyst v0.5 pre-code audit

Clean baseline b92dd57; origin is development-only, upstream push disabled and pre-push executable. Reviewed actual Source/Evidence/Claim schemas, all 32 observations and corpus exclusions, Memory store/correction/time/backend, Retrieval Layer/Index/Candidate/validator/eval/CLI, Admission/mapping/rejection history/deep provenance, CI and v0.1–v0.4 delivery documents. Existing strict schemas and existing tests remain unchanged.

Candidate proposedCategory/proposedRawValue are null; createCandidate requires a relevant visible search result, not arbitrary direct insertion. Admission accepts explicit human-reviewed fact files or exact quotations and owns all formal Evidence writes; Analyst must not import its writer or receive Memory. Proposal will be independent immutable storage outside the repository, with model/prompt/input/output snapshots and append-only promotion events. Promotion uses existing createCandidate with exact quote and temporal context, retaining mapping in Proposal lineage rather than altering Candidate schema. Two SQLite files cannot share an atomic transaction; deterministic Candidate creation and retryable promotion event provide crash-safe recovery, not distributed atomicity.

CoreWeave gold: 32 unchanged formal facts, 19 have indexed PDF Source/page, 13 release facts lack faithful bytes and must remain unavailable. Some PDF facts are transformed strings/boolean, unsupported by current Admission literal mapping. Annual tables contain multiple years; extraction validation must abstain rather than infer ambiguous bindings. Gold coverage and extraction performance are reported separately. No parser/BM25/chunk/ground-truth changes and no real semantic provider.

Provider is a pure structured JSON analysis interface with no tools/Memory/Claim state. Default is unavailable; deterministic test providers are explicitly marked mock, never real-model benchmarks. Source bytes are untrusted data. Exact statement=quote and conservative numeric/unit/period/category checks protect conversion; they do not prove all financial semantics or a real model's injection resistance. Replay/Audit eligibility is checked before provider invocation and again on validation/promotion. Unknown periods/units remain preserved but not convertible by default.
